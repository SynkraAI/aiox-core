# Jack -- 3D Creator

3D creator portfolio landing page. Standalone Vite + React + TypeScript app.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Development

```bash
cd apps/jack-portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Sections

1. `HeroSection` -- navbar, gradient hero heading, magnetic portrait, contact CTA
2. `MarqueeSection` -- scroll-driven dual-row image marquee
3. `AboutSection` -- decorative 3D corner art, scroll-revealed bio text
4. `ServicesSection` -- staggered list of five services
5. `ProjectsSection` -- sticky-stacking project cards
